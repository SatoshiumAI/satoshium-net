# SATOSHIUM — Proposed Pilot Participant Task Sheet

**Date:** 2026-10-24  
**Status:** DRAFT FOR FOUNDER REVIEW — NOT DISTRIBUTED  
**Pilot:** Proposed 3–5 voluntary participants, invitation only.

## Before starting

This is an optional evaluation of public **demonstration** services, not an operational certification process. Use sample or fictional information only: no personal credentials, private keys, confidential records, production agent identifiers, real financial actions or institutional approval tokens.

Aegis sends provided sample actor identifiers to its public inspection API. Agent Governance and Verification Ledger compute their demo records locally in the browser. These pages use Cloudflare Web Analytics for general pageview measurement and request a shared footer from satoshium.link. Associated infrastructure logging and retention have not yet been verified for the proposed pilot. Analytics cannot prove who participated or whether a task was completed. Participation and any feedback are optional; you may stop at any time.

**Task-sheet distribution and actual consent have not been authorized by this document.** If this notice is presented to real participants, it must first be finalized with an approved feedback channel, privacy arrangement and contact/withdrawal process.

## Task A — Find and inspect Aegis

1. Visit https://satoshium.net/services/
2. Find **Try Aegis Inspection** without using a provided direct link.
3. Choose the built-in preset `actor-a,actor-b`.
4. Run Inspection and inspect the JSON result. Stop if the response reports an error.
5. In your own words: **Did the tool activate, modify or certify an agent?**

## Task B — Evaluate a fictional Governance action

1. Return to the Services page and open **Try Agent Governance**.
2. Select **Load Demo Example** to populate synthetic example values.
3. Run the reference evaluation and locate its decision and explanation.
4. Download the JSON record and try **Verify Governance Record Integrity**.
5. In your own words: **Does an APPROVED decision authorize any real agent to execute an action?**

## Task C — Generate a Verification Ledger record

1. Return to Services and open **Try Verification Ledger**.
2. Use fictional agent and rule names to generate a sample local ledger record.
3. Download the JSON and invoke **Verify Ledger Record Integrity**.
4. Optionally import the example Governance JSON from Task B.
5. In your own words: **Does a successful SHA-256 check prove who created the record? Does Verification-ready TRUE prove a Bitcoin transaction?**
