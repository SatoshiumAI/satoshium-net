# ⚙️ Installation Guide

This document describes how to obtain and work with the **satoshium-net**
infrastructure repository locally.

The repository contains documentation, system catalogs, and service interface
surfaces supporting the infrastructure layer of the Satoshium platform.

---

# 🧭 Purpose

The satoshium-net repository provides infrastructure visibility for:

- systems catalogs
- service interfaces
- governance workflows
- verification ledger surfaces
- signal coordination pathways

Local installation allows contributors to review and extend infrastructure
documentation in a structured environment.

---

# 📦 Clone the Repository

Clone the repository using:

git clone https://github.com/satoshiumai/satoshium-net.git

Then enter the project directory:

cd satoshium-net

---

# 🧱 Repository Structure Overview

Key infrastructure directories include:

/systems/
/services/
/signal/
/docs/

These directories define operational coordination surfaces exposed through:

https://satoshium.net/

---

# 🌐 Local Preview

Most infrastructure files are static Markdown or HTML documents and may be
viewed locally without a build environment.

Open directly in a browser:

index.html

Or preview documentation in a Markdown viewer.

---

# ⚙️ Editing Infrastructure Surfaces

When editing infrastructure content:

Maintain alignment with:

- system registry identifiers
- service registry surfaces
- infrastructure protocol expectations
- governance workflow definitions

Avoid introducing architectural changes that belong in:

https://satoshium.ai/

---

# 📡 Deployment Model

The satoshium-net repository supports static deployment through:

GitHub Pages

Infrastructure updates become visible publicly after repository updates are published.

---

# 🔗 Relationship to Platform Repositories

This repository operates alongside:

satoshium-ai
satoshium-info
satoshium-xyz

Each repository supports a different coordination layer within the Satoshium platform.

---

# 🧾 Installation Status

Status: Active

No build pipeline is required to review infrastructure documentation surfaces.
